# Agentic pack findings

Runtime notes written by the product-write harness when a pack has nothing else to
mutate (clean gates / advisory-only).

- One markdown file per pack id (created on demand; not pre-seeded).
- Keep entries short and path-cited (`apps/…`, `scripts/…`, gate command).
- Do not paste external research briefs, invented patches, or generic advice here.
- These files are operator scratch — review before promoting anything into code or
  longer-lived docs under `docs/` / `wiki/`.
