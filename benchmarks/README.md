## History and comparison

On each CI benchmark commit to `main`/`master`, per-platform run snapshots are merged into `history.json` and **[compare.md](./compare.md)** is regenerated (tables + Mermaid charts). Adjust the default run window and platforms in **[compare.config.json](./compare.config.json)**.

Local runs write `latest.run.json` next to `latest.md`; **history append** runs in the **commit-benchmarks** CI job. To refresh **compare.md** from existing `history.json` files locally: `npm run compare --workspace=@rianell/benchmark-runner`.

## Run locally

From the repository root:

1. `npm ci`
2. `npm run build:web:apk` (minified PWA) and `npm run build:react` (Capacitor `dist/`) as needed.
3. `npx playwright install chromium` once (from repo root after `npm ci`).
4. `npm run benchmark` — writes Markdown under `benchmarks/`.
5. **`npm run benchmark:tier-matrix`** — Playwright tier 1–5 matrix (see [toolkit/AGENT-RUNBOOK.md](./toolkit/AGENT-RUNBOOK.md)).
6. **`npm run benchmark:ai-all`** — AI engine microbench (package, layers, algos, RN) + `benchmark:ai-verify -- --strict`.
