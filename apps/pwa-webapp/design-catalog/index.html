React Native parity gaps

PWA patterns not yet mirrored in RN design tokens / components.

  • Settings carousel — RN uses screen stack; no swipe carousel equivalent.
  • Theme choice chips — four global themes in PWA; RN theme picker partial.
  • Toggle switch styling — RN uses platform Switch; custom mint styling differs.
  • Tab bar — PWA bottom nav + desktop tabs; RN Expo Router tabs separate layout.
  • Home hero card — adaptive layout / scroll-reveal not ported to RN Home screen.
  • ApexCharts views — web-only chart library; RN uses different chart stack.
