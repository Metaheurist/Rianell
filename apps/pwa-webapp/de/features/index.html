Alles an einem Ort

Eine App, mit der Sie Ihre chronische Erkrankung verfolgen, besser verstehen und Informationen darüber austauschen können

Rianell ist eine kostenlose, quelloffene App für die persönliche Gesundheitsüberwachung. Erfassen Sie Symptome und Vitalwerte in Sekundenschnelle, erkennen Sie Trends mithilfe von KI direkt auf Ihrem Gerät und erstellen Sie übersichtliche Berichte für Ihr Behandlungsteam – wobei Ihre Daten stets verschlüsselt und privat bleiben.

Kostenlos starten – keine Registrierung erforderlich Registrieren Sie sich, um Daten zu synchronisieren und anderen zu helfen

Erfassung von Symptomen und Vitalwerten

Erfassen Sie schnell und einfach Informationen über Schmerzen, Müdigkeit, Symptome, Gewicht, Herzfrequenz, Blutdruck, Schlaf, Schrittzahl, Flüssigkeitszufuhr und mehr mithilfe einer übersichtlichen Anleitung.

Gespräche zur Überprüfung des psychischen Wohlbefindens

Persönliche Stimmungsaufzeichnung mit optionalen regelmäßigen Selbsttests im Stil des PHQ-9 und GAD-7. Die Antworten werden weder gespeichert noch hochgeladen.

KI-gestützte Erkenntnisse direkt auf dem Gerät

Wöchentliche Auswertungen, Trendanalysen und kurze Informationszusammenfassungen für medizinisches Fachpersonal werden lokal auf Ihrem Gerät erstellt – es werden keine Gesundheitsdaten an einen Server gesendet.

Anonymisierte Community

Melden Sie sich an, um sich mit anderen Betroffenen auszutauschen und anonymisierte Daten beizusteuern, damit auch andere Menschen von diesen Informationen profitieren können.

Zustandsbeschreibungen

Erfahren Sie, welche Daten Sie im Zusammenhang mit Ihrer Erkrankung erfassen sollten und wie Sie diese Aufzeichnungen nutzen können, um bessere Gespräche mit Ihren behandelnden Ärzten zu führen.

Privat und Open Source

Die verschlüsselte Cloud-Synchronisierung ist optional. Der Code ist offen zugänglich. Sie können jederzeit alle Daten exportieren oder löschen.

Warum entscheiden sich Menschen für Rianell

Für immer kostenlos

Die Hauptanwendung ist kostenlos und erfordert keine Registrierung. Melden Sie sich nur an, wenn Sie eine verschlüsselte Synchronisierung über verschiedene Geräte hinweg wünschen.

Datenschutz hat höchste Priorität

Gesundheitsdaten werden verschlüsselt und bei der Synchronisierung auf einem Server innerhalb der EU gespeichert; sie werden niemals verkauft. Die Antworten aus den Fragebögen verlassen Ihr Gerät nicht.

Funktioniert auch ohne Internetverbindung

Installieren Sie die App auf Ihrem Smartphone oder Computer und zeichnen Sie Ihre Daten weiterhin auf, auch wenn keine Verbindung besteht.
